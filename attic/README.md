# Отработавшее

Ничего отсюда не нужно для текущего пайплайна. Лежит на случай, если
понадобится посмотреть, как что делалось раньше.

**Подгонка совмещения ovary3.** `diag_align.py`, `refine_align.py`,
`refine_align_local.py`, `tps_warp.py`. Попытки свести координаты и картинку
подбором преобразования, вплоть до нежёсткой регистрации по опорным точкам.
Причина расхождения оказалась в другом: H&E был подложен от другого запуска
Xenium, то есть от физически другого среза. Пользоваться этим не надо, оно
чинит несуществующую проблему.

**Visium.** `seg_train_layer1.py`, `make_visium_mask.py`. Ветка на данных
Visium (спот 55 мкм, десятки клеток в точке). Пробовали добавить в обучение,
качества не дало.

**Заменённое.** `tcga_tsp.py` считал TSP по когорте, теперь это `collect_tsr.py`.
`tsp_bias.py` мерил смещение доли стромы у патчевой ветки. `prep_sthelar.py`
готовил обучающие .npz из STHELAR, сейчас туда ходит `sthelar_bench.py`.
`sthelar_extract.py` — разбор формата того же набора.

**Разовое.** `merge_cell_map.py` влил subtype_groups в groups в карте классов,
правка давно применена. `relabel_feat.py` без описания, назначение утеряно.
`download_demo.py` качал демо-срез с псевдо-метками по маркерам для проверки
проходимости пайплайна.
